# Parth Shah — 3D Artist & Motion Designer

A cinematic portfolio showcasing Parth Shah's work across 3D environment art, modeling, texturing, lighting, animation, and motion design.

## Live portfolio

https://artsytrate.github.io/Parth_Shah/

## Site structure

- `index.html` — portfolio content, project presentations, navigation, and contact links
- `style.css` — responsive visual system and cinematic layouts
- `script.js` — scroll reveals, gallery motion, and anchor navigation
- `assets/Projects/` — original project renders, videos, and 3D assets

## Featured work

- Ancient Temple — environment art, lighting, and rendering
- Alarm Clock — hard-surface modeling, texturing, and look development
- Ancient Well — prop modeling and asset presentation
- Fight Sequence — character animation and body mechanics
- Formula 1 Car — Maya vehicle modeling and rigging (work in progress)

## Publishing with GitHub Pages

The static site is designed to publish from the `main` branch at the repository root:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then save.

No package installation or build step is required for the static portfolio.

## Maintaining the portfolio

Keep project media in `assets/Projects/` and update the corresponding paths in `index.html` when adding or replacing work. Preserve the existing folder names and URL-encode spaces in asset URLs where needed. Large video files should be compressed for web playback before committing.
